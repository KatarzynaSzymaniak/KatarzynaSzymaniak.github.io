Neuroimaging Data Analysis: using HoloLens for Teaching Purposes

Awarded with a certificate for 'Best Student Project' in the College of Science, Department of Computer Science. This project involved rendering MRI scan volumetric data to a 3D mesh model of a human brain, which was then incorporated with Microsoft HoloLens using Unity. This created a teaching tool for medical students to address the common problem of spatial data visualization. It required excellent planning, organizational skills, and the ability to self-teach complex subjects and cross-platform game engine development.

  • Market Relevance: Medical Education, AR/VR, Spatial Computing, Human-Computer Interaction
  • Business Impact: Improved spatial data visualization for medical students, enhanced learning tools.
  • Technical Innovation: 3D rendering, Unity integration, HoloLens development, cross-platform game engine use.
